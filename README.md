# 🤖 ربات تلگرام تبدیل ویس به متن و پاسخ‌گوی انسانی (`@voiceandpasokhbot`) — نسخه ایمن پابلیک

این مخزن شامل سورس کامل، دیباگ‌شده و ایمن‌سازی‌شده ربات تلگرام `@voiceandpasokhbot` به همراه ورک‌فلو اجرای ۲۴/۷ در GitHub Actions است که به طور ویژه برای **مخازن Public گیت‌هاب** طراحی شده تا هیچ توکن، کلید API یا پیام کاربری لو نرود و کسی نتواند روی بات تبلیغ یا اسپم بزند.

## 🔒 راهنمای راه‌اندازی امن در مخزن پابلیک گیت‌هاب (بدون لو رفتن API)

1. **تعویض توکن‌های قبلی (بسیار مهم):**
   - در تلگرام وارد `@BotFather` شوید، دستور `/revoke` را بزنید و توکن جدید برای بات بگیرید.
   - در پنل Google AI Studio کلید قبلی را حذف و یک `GEMINI_API_KEY` جدید بسازید.
2. **ثبت کلیدها در GitHub Secrets (مخفی از دید عموم):**
   - وارد مخزن گیت‌هاب خود شوید و به مسیر **Settings** -> **Secrets and variables** -> **Actions** بروید.
   - روی **New repository secret** کلیک کنید و این مقادیر را بسازید:
     - `BOT_TOKEN`: توکن جدید بات تلگرام
     - `GEMINI_API_KEY`: کلید جدید Gemini API
     - `ALLOWED_USER_IDS` *(اختیاری اما بسیار پیشنهادی)*: آیدی عددی اکانت تلگرام خودتان (مثلاً `123456789` یا چند آیدی با ویرگول `123456,654321`). اگر نمی‌دانید آیدی عددی شما چیست، بعد از روشن شدن بات دستور `/id` را برای بات بفرستید تا آیدی عددی شما را نمایش دهد.
3. **اجرای ۲۴/۷:**
   - تمام فایل‌های این بسته را در مخزن گیت‌هاب خود آپلود کنید.
   - وارد تب **Actions** شوید و روی **Run workflow** کلیک کنید.

## ✨ امکانات فنی و هوش مصنوعی نسخه جدید (Gemini 3.x Power Edition)
- **🎙️ رونویسی با مدل اختصاصی `gemini-3.5-transcribe`:** بالاترین دقت تشخیص گفتار، لهجه‌ها و کلمات تخصصی با قابلیت فال‌بک به `gemini-3.8-flash`.
- **💬 پاسخ‌گویی انسانی با `gemini-3.8-flash` (سطح تفکر عمیق High):** تحلیل عمیق لحن و محتوا، بدون علائم نگارشی و تملق.
- **🧠 پشتیبانی از مدل پرچمدار `gemini-3.1-pro-preview`:** برای پردازش‌ها و تحلیل‌های سنگین با نهایت استدلال منطقی.
- **🌐 ترجمه بلادرنگ و روان:** دکمه ترجمه هوشمند دوطرفه بین فارسی و انگلیسی زیر تمامی پیام‌ها.
- **🔊 تبدیل متن به ویس با `gemini-3.8-flash-tts`:** تولید صوت طبیعی و باکیفیت و ارسال مستقیم به عنوان ویس تلگرامی.
- **⚙️ منوی تنظیمات تعاملی مدل (`/settings` یا `/model`):** امکان تغییر آنی مدل‌ها و سطح تفکر به صورت کاربرمحور با کیبورد شیشه‌ای.
- **حذف کامل توکن‌های هاردکدشده و ماسک کردن لاگ‌های `httpx`:** هیچ کلیدی در کد یا لاگ‌های عمومی تب Actions نمایش داده نمی‌شود.
- **ذخیره‌سازی رمزنگاری‌شده (`AES-256-CBC`) در کش اکشنز:** فایل دیتابیس `voice_bot.db` هرگز داخل مخزن پابلیک Commit نمی‌شود و اطلاعات کاربران و `chat_id`ها کاملاً محرمانه می‌ماند.
- **سپر ضد تبلیغات، ضد اسپم و قفل دسترسی (`ALLOWED_USER_IDS`):** مسدودسازی خودکار گروه‌ها، ربات‌ها، لینک‌های تبلیغاتی و محدودیت نرخ درخواست (Rate Limit).
